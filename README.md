# xyz-landing-page

Landing page para el producto XYZ desarrollada con Next.js.

## Objetivo

Actualizar el color y estilo del botón principal del landing page para el producto XYZ.

## Tech Stack

- **Framework:** Next.js 14+
- **Lenguaje:** TypeScript
- **Styling:** Tailwind CSS
- **Deploy:** Vercel

## Repositorio

- **Organización:** KUBBESA
- **Nombre:** `xyz-landing-page`
- **Visibilidad:** Privado
- **Branch Principal:** `main`

## Requisitos Previos

Antes de comenzar, asegúrate de tener instalado lo siguiente:

- Node.js (versión 18.17 o posterior)
- npm, yarn o pnpm

## Instalación

1. Clona el repositorio:
   ```bash
   git clone https://github.com/KUBBESA/xyz-landing-page.git
   cd xyz-landing-page
   ```

2. Instala las dependencias:
   ```bash
   npm install
   # o
   yarn install
   # o
   pnpm install
   ```

3. Configura las variables de entorno:
   Copia el archivo `.env.example` a `.env.local` y ajusta las variables necesarias.
   ```bash
   cp .env.example .env.local
   ```

## Scripts Disponibles

En el directorio del proyecto, puedes ejecutar:

- `npm run dev`: Inicia el servidor de desarrollo.
- `npm run build`: Construye la aplicación para producción.
- `npm run start`: Inicia el servidor de producción.
- `npm run lint`: Ejecuta el linter sobre el código.

## Características Implementadas

### Botón Principal (CTA)

El botón ha sido actualizado según los siguientes requerimientos funcionales:

- **Ubicación:** Centrado en la pantalla.
- **Texto:** "CHICHO - JARVIS"
- **Color de fondo:** Amarillo.
- **Borde:** Estilo dashed color negro.
- **Borde redondeado:** 12px.

## Criterios de Aceptación

- [x] El botón debe estar en el medio de la pantalla con las características descritas.
- [x] No se ha eliminado ninguna información existente del landing.
