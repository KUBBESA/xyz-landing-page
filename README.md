# xyz-landing-page

Landing page for product XYZ featuring a specialized CTA button.

## Tech Stack

- **Framework:** Next.js 14+
- **Language:** TypeScript
- **Styling:** Tailwind CSS
- **Deployment:** Vercel

## Prerequisites

Before you begin, ensure you have the following installed:
- Node.js 18.17 or later
- npm, yarn, or pnpm

## Getting Started

### Installation

1. Clone the repository:
```bash
git clone https://github.com/KUBBESA/xyz-landing-page.git
```

2. Navigate to the project directory:
```bash
cd xyz-landing-page
```

3. Install dependencies:
```bash
npm install
```

4. Set up environment variables:
Create a `.env.local` file in the root directory. Do not commit this file to version control.

### Running the Development Server

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser.

## Available Scripts
